Prism · Automatic connections

Version 1.9 · Windows x64 · Source, documentation and releases

Setup

Extract a release and run Setup.cmd. Python 3.11–3.14 (64-bit) is required. Setup installs pinned dependencies in this folder's virtual environment. No administrator access is needed. Releases include .NET; source builds require the .NET 8 SDK.

Codex

Install and sign in to Codex CLI. Prism reads the active account's quota via the CLI app server. If verification fails, historical session readings are labeled stale and cannot trigger reset reminders.

Cursor Individual and OpenCode Go

Sign in through the provider's own app, then enable existing-sign-in reuse in ⋯ → Connections. Read-only requests go only to its own usage endpoint. Prism does not save or refresh raw credentials. Go subscription entitlement is required; a generic Zen key alone is insufficient.

Claude CLI (recommended)

  1. Install Claude Code.
  2. Choose Sign in to Claude in Prism, or run Connect Claude CLI.cmd.
  3. Complete subscription sign-in and first-run setup. API-key authentication is not subscription quota.
  4. Return to Prism and refresh. It reads the built-in /usage panel every five minutes, with hooks and MCP disabled. No model prompt is sent.

CLI interface changes can require an adapter update. CLI readings currently have percentages but no parsed reset times.

Optional Claude browser sync

  1. Run Install Claude Browser Sync.cmd to register the current-user native messaging host for Chrome and Edge.
  2. Open chrome://extensions or edge://extensions, enable Developer mode, choose Load unpacked, and select this installation's browser-extension folder.
  3. Sign in at claude.ai.
  4. Open the extension. Explicitly choose your account if multiple are available, then refresh.

It checks every five minutes while the browser runs. Only numeric quota crosses into Prism, never cookies or conversations. This is an unpacked extension, not a browser-store distribution. Its manifest key is public extension identity.

Optional Claude status-line feed

Connections can install a feed command in Claude settings. Prism asks before adding a new status line and preserves an existing one. To integrate with an existing script, invoke "<Prism folder>/.venv/Scripts/python.exe" "<Prism folder>/claude_feed.py" with the status JSON on stdin, while preserving your current display output. Only recognized numeric quota fields are retained; readings exist only if Claude supplies them. Reconnect after moving the Prism folder.

Controls, clocks and alerts

Drag the title to move; drag the lower-right grip to resize. The widget never scrolls. F5 refreshes, Ctrl+P pins, Ctrl+M switches density, Ctrl+, opens settings and Esc closes. The ⋯ menu includes global timezone clocks, reset reminders, Free RAM and diagnostics. Clocks follow daylight saving. Reminders default to 30 minutes before a known reset when more than 10% remains, with one alert per reset. Prism must be running, either visible or in the system tray.

Capacity intelligence

More → Capacity & resets shows upcoming reported resets and cautious local estimates. Window history separates accounts with opaque local scopes; old aggregate history is retained separately. Predictive alerts are off by default. Click the tray icon for a cached capacity view, then Show Prism to restore. See the method and limitations.

Settings and history

Settings now contains General, Refresh rates, Metrics, Alerts, Profiles and Updates tabs. Choose English, Hindi, Spanish or French and 12/24-hour clocks. Hide or reorder metrics, save layout profiles, enable tray/startup, and set independent provider intervals. Low-quota alerts default to 20%. More → Usage history shows 24-hour, weekly and 30-day local allowance charts. Manual update checks download a size/SHA-256-verified ZIP; installation remains manual. See the full guide.

Help and removal

Use ⋯ → Diagnostics for a report without account details or paths. A dash means unknown quota. Read Troubleshooting and Privacy; never share the data folder. To uninstall, close Prism, remove the optional extension/native-host registration and any Prism status-line command, then remove the extracted folder. Disable optional Start with Windows before removing the folder. No system service is installed.

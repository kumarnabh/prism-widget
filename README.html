Prism · Automatic usage

A glass-style Windows widget. No manual quota numbers.

Launch

Double-click Prism.exe. Drag its title to move; ◇ pins it, − toggles compact density (all readings stay visible), × or Escape closes it. Drag the bottom-right corner to resize. The dashboard never scrolls. Below 640 pixels tall it switches to a metrics-only grid: descriptive labels, titles and timestamps disappear, leaving colored icons, numbers and small meters. The eight system and AI metrics combine into two, four or eight columns according to width. Hover for full labels, units, freshness and connection details. CPU and memory charts appear only when there is room. Wider layouts can shrink to a thin strip, down to 120 pixels tall; use □ to restore the detailed layout. Padding, chart height and card layout adapt to the available space. Smaller windows use compact AI tiles, wider windows use two or four columns, and a final fit adjustment keeps every primary reading and control visible. Hover over a card for full quota details and connection messages. Fit height adjusts to the current layout, and size, position and compact mode are saved on exit. Keep this folder together. Requires .NET Desktop Runtime 8 and Python 3.14 (64-bit), required on the host computer; the bundled CLI terminal dependency targets that Python version.

The ⋯ menu keeps pinning, fit height, Free RAM and Connections available in every layout. Keyboard shortcuts: F5 refresh, Ctrl+P pin, Ctrl+M toggle density, Ctrl+, connections, Esc close. CPU and RAM charts keep up to 72 seconds of real samples. Current, stale, error and unavailable readings use green, amber, pink and gray status dots with explanatory tooltips. Launching Prism again brings the existing window forward. Dashboard, Focus and Ribbon presets are available in the same menu; the detailed height is remembered. Ring gauges show CPU and RAM load. Quota bars turn amber at 25% remaining and coral at 10%. Reset countdowns follow the limiting quota window; exact reset times appear on hover. The disk bar shows free space, matching its number.

Cursor Individual and OpenCode Go

Settings → Allow my existing Cursor / OpenCode sign-ins enables automatic account quota. This is opt-in and disabled in a fresh checkout.

  • Cursor uses its desktop sign-in to read included, Cursor-model and other-model quota. The headline shows the lowest remaining percentage across returned windows.
  • OpenCode Go uses its saved Go key to read 5-hour, weekly and monthly quota. If the saved key has no subscription, reconnect it using OpenCode’s /connect → OpenCode Go with the key from your subscribed workspace. Never paste a key in chat.

Server checks run every five minutes. The widget rereads local results each minute. Rate-limited checks pause for fifteen minutes. Prism never rotates or rewrites credentials.

Claude: automatic CLI connection

  1. Choose Settings → Sign in to Claude or run Connect Claude CLI.cmd.
  2. Use your Claude subscription in Claude Code's official sign-in flow.
  3. Complete any first-run theme or folder-trust setup in the CLI, then close that terminal. Click Refresh in Prism or wait up to one minute.

Every five minutes Prism launches a hidden terminal for Claude Code’s built-in /usage panel. It reads the displayed session and weekly quota bars, then closes its own CLI process. No model prompt is sent. Hooks, model tools, Chrome integration and MCP servers are disabled for this reader. Credentials stay managed by Claude Code. The noninteractive claude -p /usage command reports session cost and cannot supply these subscription bars.

The reader is tested against the installed CLI 2.1.161 labels. Future CLI layout changes can require an adapter update. An unreadable panel shows unavailable or a short-lived stale reading; it never turns missing data into zero. A valid subscription sign-in and completed CLI setup are required for live readings. Browser sync and a pre-existing status-line feed remain optional fallbacks; no extension is required for the CLI path.

Free RAM

Click Free RAM in the widget, select Prism or specific app processes, then choose Free selected RAM. Only Prism is selected initially. This asks Windows to trim eligible working-set pages. Apps stay open, files and conversations are untouched, and no administrator/debug privileges are requested. Protected or exited processes are skipped. The reported reduction is measured working-set size, not guaranteed system RAM freed; pages may return immediately and apps can briefly respond more slowly.

Freshness and meaning

  • CPU, RAM, free disk and Ethernet/Wi-Fi traffic update every two seconds.
  • Codex reads recent local quota events with signed-in CLI fallback.
  • Live means a just-fetched server response. Recent means an automatic cache within ten minutes. Browser means a Claude browser capture within ten minutes.
  • Stale retains the original capture timestamp. Windows with known expired reset timestamps are removed. CLI display readings have no parsed reset timestamp and expire after ten minutes without a successful refresh. A dash means unknown, never zero.
  • Percentages measure subscription allowance, not a guaranteed number of future tokens. Manual-entry files are no longer used.

Privacy

Opt-in credential reuse sends authentication only to https://cursor.com/api/usage-summary and https://opencode.ai/zen/go/v1/usage. Redirects are refused. Raw credentials are never printed, cached by Prism or used for inference. Quota and one-way credential fingerprints stay under data. Disable reuse in Settings to stop requests.

The browser extension has host permission only for claude.ai, plus alarms, storage and native messaging. Its local host accepts only the fixed extension ID and validates quota messages up to 8 KB. Remove the extension to stop browser sync. The registrations are HKCU\Software\Google\Chrome\NativeMessagingHosts\com.prism.widget and HKCU\Software\Microsoft\Edge\NativeMessagingHosts\com.prism.widget. No startup task is installed.

Verification

42 local quota and regression tests cover known zero, missing/malformed data, expiry, consent, current Cursor schema, Go windows, redirect refusal, cache behavior, malformed-cache recovery, independent source fallbacks and quota-only bridge validation. Native self-tests cover live sensors, pinning, compact mode, three size presets, quota validation and eight narrow/wide layouts. RAM trimming was checked in the initial release; it was not repeated in this visual update. Eight no-scroll layouts, including 340 × 220 and a 1200 × 120 metrics strip, pass bounds checks for all primary readings and controls; compact, medium and wide renders were inspected. This layout update does not exercise the RAM action again. Local checks do not establish live provider authentication.
